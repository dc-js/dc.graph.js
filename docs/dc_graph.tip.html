Tippy.js tooltip support for dc.graph.js

Modern replacement for d3.tip using tippy.js for better performance and features.

Members

content

Specifies the async function to generate content for the tooltip. This function has the signature async function(d), where d is the datum of the thing being hovered over. The function should return a promise that resolves to the HTML content string.

Source:
  • tip.js, line 153

direction

Specify the direction for tooltips. Currently supports the cardinal and intercardinal directions: 'n', 'ne', 'e', etc.

Source:
  • tip.js, line 141

table

Generates a handler which can be passed to tip.content to produce a table of the attributes and values of the hovered object.

// show all the attributes and values in the node and edge objects
