(static) diagram(parent, chartGroupopt) → {Object}

diagram is a dc.js-compatible network visualization component. It registers in the dc.js chart registry and its nodes and edges are generated from crossfilter groups. It logically derives from the dc.js baseMixin, but it does not physically derive from it since so much is different about network visualization versus conventional charts.

Parameters:
Name Type Attributes Description
parent String | node

Any valid d3 single selector specifying a dom block element such as a div; or a dom element.
chartGroup String <optional>

The name of the dc.js chart group this diagram instance should be placed in. Filter interaction with a diagram will only trigger events and redraws within the diagram's group.
